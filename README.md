# C Visual Static Analyzer

Desktop aplikacija za vizuelnu statičku analizu C koda i AI asistenciju pri učenju programiranja.

## Glavne funkcionalnosti

- C code editor
- Otvaranje i čuvanje .c fajlova
- GCC compile & run
- Cppcheck statička analiza
- Code metrics
- Vizuelno označavanje grešaka
- AI asistent za objašnjavanje koda
